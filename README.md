# CV Strategist – Resume & CV Writing Website

## 📌 Project Overview

**CV Strategist** is a responsive, multi-page website designed for a professional CV and resume writing service. The platform aims to help job seekers improve their professional profiles and stand out in competitive job markets.

The website provides information about CV writing services, pricing packages, the writing process, professional writers, and career-related resources.

## ✨ Features

- **Home Page:** Introduces the CV Strategist platform and highlights its services.
- **Why Choose Us:** Showcases the benefits of professional CV writing, including increased callbacks and career opportunities.
- **Pricing & Packages:** Displays available service packages.
- **How It Works:** Provides information about the service journey.
- **Our Process:** Explains the different stages of CV development, from consultation to final delivery.
- **Our Writers:** Introduces the professional writing team.
- **Blog Section:** Provides career-related articles and job application tips.
- **Login Popup:** Interactive login popup with input fields and file upload option.
- **Responsive Navigation:** Navigation menu with a mobile-friendly toggle.
- **FAQ Section:** Answers frequently asked questions.

## 🛠️ Technologies Used

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layouts, and responsive design.
- **JavaScript** – Interactive elements, navigation menu, and popup functionality.
- **Font Awesome** – Icons.
- **Google Fonts** – Typography.

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

4. Explore the website and navigate through its different sections.

No additional installation or server configuration is required.

## 🎯 Project Objective

The main objective of this project is to create an attractive and user-friendly online platform for CV and resume writing services. It focuses on presenting professional services in an organized way while providing visitors with an easy navigation experience.
